# Attribution Guidelines

All output generated by commands in this repository should include attribution to indicate it was AI-assisted.

---

## Why

Attribution provides transparency about AI involvement, helps teams track AI-assisted work, and ensures proper credit.

---

## What to Include

### Commits

Add to the end of commit messages:

```
Co-Authored-By: Claude <noreply@anthropic.com>
```

### Pull Requests

Add to the bottom of PR descriptions:

```markdown
🤖 Generated with [Claude Code](https://claude.com/claude-code)
```

### Tickets, Reviews, and Documents

Add to the bottom of any generated markdown file, ticket, or review:

```markdown
🤖 Generated with [Claude Code](https://claude.com/claude-code)
```

---

## When to Include

| Output Type | Attribution |
|-------------|-------------|
| Git commits | `Co-Authored-By` in commit message |
| Pull requests | `Generated with Claude Code` footer + `Co-Authored-By` in commits |
| GitHub issues/tickets | `Generated with Claude Code` footer |
| Review documents (markdown files) | `Generated with Claude Code` footer |
| CI reports | `Generated with Claude Code` footer |
| Slack messages or comments | `Generated with Claude Code` one-liner |

---

## When NOT to Include

- **Analysis-only responses** shown directly in the terminal (not saved to a file or posted anywhere)
- **Conversational answers** to user questions
- **Edits to existing files** where the user is the author (e.g., fixing a typo in their code)
